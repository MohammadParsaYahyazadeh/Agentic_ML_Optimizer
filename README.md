# Agentic ML Optimizer

An intelligent AutoML framework that leverages LLM-driven agents and Optuna optimization to automate the machine learning workflow.

## Features

- 🤖 LLM-powered decision-making agent
- ⚡ Automated hyperparameter optimization with Optuna
- 🛠 Automatic feature engineering
- 🔄 Automated preprocessing pipeline generation
- 📊 Cross-validation and out-of-fold evaluation
- 🏆 Leaderboard tracking for model comparison
- 🌲 Supports multiple ML models including:
  - LightGBM
  - Random Forest
  - Logistic Regression
- 📈 Performance visualization and reporting

## Architecture

The system automates the complete ML pipeline:

1. Data Loading
2. Feature Engineering
3. Data Preprocessing
4. Model Selection
5. Hyperparameter Optimization
6. Cross-Validation Evaluation
7. Leaderboard Generation
8. Final Model Training

## Technologies Used

- Python
- Scikit-learn
- Optuna
- LightGBM
- Transformers (Hugging Face)
- PyTorch
- Pandas
- NumPy
- Plotly

## Example Use Case

The framework demonstrates automated optimization on the Titanic dataset, automatically discovering high-performing configurations through intelligent search and agent-based reasoning.
